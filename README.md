# BAE Systems: Predictive Maintenance of Hydraulic Systems

MSc Data Science — DATA70202 | University of Manchester | Team P3 | May 2026


**Overview:** Data-driven predictive maintenance framework for hydraulic fault diagnosis, built in partnership with BAE Systems. We train and evaluate 5 ML classifiers across 5 hydraulic components using a dual validation strategy — random split for feature validation and temporal block split at cycle 1,664 for deployment simulation.
